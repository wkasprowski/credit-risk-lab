# Primary references

The implementation uses synthetic data rather than a downloaded borrower dataset. Numeric policy choices are project assumptions. References inform concepts and tool usage, not a claim of complete compliance.

- [BIS — IFRS 9 and expected loss provisioning](https://www.bis.org/fsi/fsisummaries/ifrs9.pdf): stages, twelve-month versus lifetime expected loss and the timing of default versus recovery.
- [AASB 9 public text, February 2025](https://standards.aasb.gov.au/aasb-9-feb-2025): public standard text corresponding to IFRS 9 concepts; paragraphs 5.5.9, 5.5.11 and B5.5.37. This is not a source of local prudential regulation.
- [scikit-learn probability calibration](https://scikit-learn.org/stable/modules/calibration.html): independent calibration data and probability assessment. The repository pins scikit-learn 1.8.0; current web documentation can describe a later version.
- [Python 3.12 on Windows](https://docs.python.org/3.12/using/windows.html): launcher, installation and environments.
- [Power BI Desktop](https://learn.microsoft.com/en-us/power-bi/fundamentals/desktop-get-the-desktop) and [Csv.Document](https://learn.microsoft.com/en-us/powerquery-m/csv-document): manual report creation and CSV import.
- [Playwright browser installation](https://playwright.dev/docs/browsers): optional browser testing.
- [GitHub — adding locally hosted code](https://docs.github.com/en/migrations/importing-source-code/using-the-command-line-to-import-source-code/adding-locally-hosted-code-to-github): manual publication commands.

Original implementation and documentation were developed with AI assistance. This cleaned release preserves the original numerical modelling code. The release validation report documents executed checks and limitations.
